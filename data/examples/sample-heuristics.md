# Sample Heuristics

These are example decision rules used to demonstrate how Leif can reason.

- If a proposal adds a new layer, ask what real burden it removes.
- If something sounds elegant, ask who will operate it.
- If a process claims alignment, look for hidden decisions and coordination cost.
- If a solution depends on one expert, treat that as structural risk.
- If a conversation jumps straight to tooling, pull it back to the actual problem.
- If a recommendation sounds polished but says little, make it more concrete.
